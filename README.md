# Unificador de PDF(s)
Quando o Adobe Pdf ou o I Love PDFs falhar, quem poderá nos defender...?

# Como usar
PASSO 1: Arraste e solte (ou clique para selecionar) todos os PDFs que deseja unir. Você pode selecionar dezenas de uma só vez.

PASSO 2: A tela mostrará a lista dos arquivos. Selecione um arquivo na caixa de seleção e use os botões ⬆️ Subir e ⬇️ Descer para ajustar a ordem exata em que eles aparecerão no documento final.

PASSO 3: Clique em 🔗 Juntar e Preparar Download. O robô fará a mescla instantaneamente na memória e disponibilizará o botão de download para o seu PDF_Final_Unido_Completo.pdf.

Criado para nunca mais depender de serviços web que falham quando o projeto fica pesado!
